# EGAS — проверка расходов УК

Работающий прототип сверки начисления, акта и договорных условий по одной услуге за один период. ИИ извлекает значения с цитатами, программа проверяет арифметику и сопоставимость документов. Пользователь проверяет замечания, уточняет значения и скачивает результат.

**Статус версии:** текущий прототип использует внешний ИИ через OpenRouter или OpenAI. Полностью локальная модель в этой версии не реализована. Запуск интерфейса на localhost не означает локальную обработку ИИ.

## Быстрый запуск

Нужен Node.js 22.13+ (ветка 22) или более новая поддерживаемая версия и npm.

1. Клонируйте репозиторий и перейдите в его папку.
2. Установите зависимости: `npm ci`.
3. Соберите приложение: `npm run build`.
4. Проверьте сборку: `npm test` и `npm run validate`.
5. Запустите: `npm run dev`.
6. Откройте http://127.0.0.1:4173/.

Без ключей доступны кнопки учебных примеров и «Открыть учебную сверку». Эти результаты подготовлены заранее, что явно отмечено в интерфейсе. Для другого порта: `node scripts/preview.mjs 4174`.

## Реальное извлечение ИИ

Скопируйте `.env.example` в `.env.local`, заполните ключ выбранного провайдера и перезапустите сервер. Не публикуйте ключ. При наличии обоих ключей используется OpenRouter. Модель по умолчанию — `openai/gpt-4.1-mini` для OpenRouter, `gpt-4.1-mini` для OpenAI.

Запрос выполняется только по кнопке «Извлечь условия с ИИ». Он платный по тарифу провайдера. Тексты документов передаются серверу приложения и далее внешнему провайдеру. Используйте только данные, на такую передачу которых есть разрешение.

## Проверка примеров

- Март: исходный фрагмент отчёта не определяет НДС — соответствующие денежные сравнения блокируются. Проверка договорного расчёта акта выявляет разницу 120 ₽. Ручное подтверждение сопоставимости НДС открывает другие сравнения и отмечается в результате как ручное уточнение.
- Сентябрь: исходная сумма также отличается от произведения площади и ставки на 120 ₽.
- Контрольный пример: синтетический комплект с согласованными суммами и явно указанным НДС.

Учебные фрагменты восстановлены из переписки симуляции; они не являются оригиналами документов УК. Разницы одного начисления не складываются. Найденное замечание не доказывает экономию, переплату или нарушение.

## Файлы и ограничения

- Текст, TXT/CSV/TSV UTF-8, XLSX и PDF с текстовым слоем.
- До 6 МБ на файл и 28 000 символов на документ. XLSX — до пяти листов и 2000 строк на лист, PDF — до 20 страниц.
- Скан без текстового слоя не распознаётся. Многострочная сверка и несколько услуг одновременно не реализованы.
- Формулы Excel не пересчитываются: используются сохранённые значения.
- Цитаты и числа проверяются на присутствие в исходном тексте. Это не заменяет проверку смысла извлечения специалистом.
- Неизвестный НДС, разные периоды и несовпадающие услуги блокируют соответствующие сравнения.
- Данные и решения находятся в памяти страницы; после перезагрузки они теряются. Сохраните текстовый отчёт до закрытия.

## Обработка данных

Файлы читаются в браузере. Для ИИ передаётся извлечённый текст. Приложение не создаёт постоянный серверный архив документов; `store:false` отправляется провайдеру. Это не гарантия отсутствия хранения или обработки у внешних провайдеров и инфраструктуры.

В репозиторий не входят ключи, рабочие env-файлы, финансовые расчёты, временные данные и локальные результаты проверок. Сервер разработки слушает только 127.0.0.1.

## Структура

- `src/audit.mjs` — схема извлечения, проверка цитат и расчёты.
- `worker/index.js` — серверные маршруты и вызов провайдера ИИ.
- `web/` — интерфейс и чтение файлов в браузере.
- `scripts/` — сборка, локальный запуск и проверка артефакта.
- `tests/` — проверки правил и серверных маршрутов без платных ИИ-запросов.

Сборка создаёт единый ESM Worker в `dist/server/index.js`, включая браузерные ресурсы и PDF.js. Минимальный `.openai/hosting.json` сохранён для совместимости формата сборки; привязки к чужому проекту размещения нет. В аккаунте EGAS подключён Cloudflare Workers Builds: изменения в ветке `main` запускают проверки, сборку и публикацию сайта. Команда сборки: `npm test && npm run build && npm run validate`; публикация: `npx wrangler deploy`. При ошибке проверок новая версия не публикуется.

PDF.js (Mozilla Foundation, Apache License 2.0) устанавливается из npm. Его лицензия доступна в работающем приложении по адресу `/vendor/LICENSE`.

## Опубликованная версия

Демо: https://egas-expense-audit.egas-expense-audit.workers.dev/

Приложение размещено в Cloudflare Workers. Для повторной публикации в своём аккаунте: установите зависимости, авторизуйте Wrangler и используйте npm run deploy. В wrangler.jsonc укажите свой account_id или удалите его для выбора аккаунта. Секрет OPENROUTER_API_KEY задаётся отдельно командой wrangler secret put OPENROUTER_API_KEY; его нельзя записывать в конфигурацию или исходники. Платный тариф для текущего размещения не подключался; действуют ограничения бесплатного тарифа. Запросы OpenRouter оплачиваются отдельно.

Скрипт scripts/cloudflare-secret.mjs позволяет передать ключ из указанного локального env-файла через stdin официальному Wrangler без вывода значения ключа. Не коммитьте файлы с ключами или служебные каталоги Wrangler.
